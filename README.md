# RagSume

Using a Retrieval Augmented Generation bot to return relevant stuff from my md documents of my life.

## Learned Concepts

Concepts I learned or exercised in this project.

- Retrieval Augmented Generation (RAG)
- LangChain text splitting
- FAISS vector Index
- OpenAI Embedding & Generation APIs
- Hugging Face open model sentence transformers (V0 implementation, removed for open AI api embedding model for Render memory capacities)
- Render cloud deployment
- Fast API backend
- REST API requests
- CORS middleware
- Semantic search & information retrieval
- Frontend API requests
- Env vars & API key management
