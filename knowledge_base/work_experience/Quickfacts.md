# QuickFacts — Software Developer & Data Analyst Co-op Winter 2025

## Overview

I worked at QuickFacts as a Software Developer and Data Analyst Co-op Student from January 2025 through April 2025.

My work at QuickFacts combined software development with data analysis and involved contributing to the company's CMS and supporting the development of internal and user-facing functionality.

This experience gave me practical exposure to full-stack web development, backend APIs, databases, analytics, and working within an existing software codebase.

## Software Development

My primary development work involved building and modifying features for the QuickFacts CMS platform.

I worked with both frontend and backend technologies, giving me experience across multiple parts of a web application.

### Frontend

I worked with React and JavaScript to develop and modify frontend functionality.

My frontend work involved working within an existing React application and understanding how components, data, and user interactions fit together within the larger application.

### Backend

I worked with Node.js and Express to develop and interact with backend APIs.

This gave me experience understanding how frontend applications communicate with backend services and how backend logic connects application functionality to stored data.

### Database

I worked with MongoDB as part of the backend infrastructure.

I also worked with Prisma and Prisma schemas, gaining experience working with database models and the structure of data used by the application.

I wrote JavaScript scripts that were used to import data into the system, giving me experience working with data programmatically rather than only interacting with data through the application's user interface.

## Data Analysis and Analytics

In addition to software development, I worked with product analytics.

I used Mixpanel to analyze user behavior and product usage.

This provided experience working with data generated by a real software product and thinking about how application usage can be measured and understood through analytics.

## What I Learned

This experience helped me understand the relationship between frontend development, backend services, databases, and analytics within a real software product.

It also gave me experience working in an existing codebase rather than building every component of an application from scratch.

A major takeaway from the experience was the importance of understanding how different parts of a software system interact. A feature might require changes across the frontend, backend, database, and analytics layers.

## Relevance to Future Roles

This experience is relevant to software engineering, data science, and AI/ML roles because it provided practical experience building software, working with data, and understanding how technical systems operate in a real organization.

It is particularly relevant when discussing full-stack development, backend development, data analysis, APIs, databases, and the application of data within software products.
